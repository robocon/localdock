## อ่านจ้า
ตัวนี้เทสใน local ผ่าน WSL2<br>
ความตั้งใจเดิมคือ อัพเกรดโค้ดเก่าที่เป็น PHP5.1.6 ให้ไปใช้งาน PHPตัวใหม่ๆได้

## docker-compose.yml

| Color             | Hex                                                                |
| ----------------- | ------------------------------------------------------------------ |
| webold | ตัวเก่า เอาไว้เทสว่าตอนย้ายจากเซิฟเวอร์มันยังโอเครึป่าว<br>Port 80 |
| web | ก่อนจะขึ้นไป PHP8 เทสกับ PHP5.3 ก่อนว่ามันพอจะโอเครึป่าว(จริงๆก็ไม่โอเคล่ะ)<br>Port 8053 |
| web2 | PHP8<br>Port 8080 |
| db | MySQL อิงตามตัวเดิม<br>Port 3308 |
| volumes | ไปแก้กันเอาเองนะตามที่บอกไปด้านบนคือเทสในเครื่อง<br>Default ที่ใช้ในเครื่องนี้จะเป็น /mnt/d/docker/www ก็ไปแก้กันเอาเอง |

## PHP 5.2.17 
อ้างอิงมาจากตัวนี้ https://github.com/LibreCodeCoop/docker_php52 เสร็จแล้วก็ให้ Gemini มาช่วยดูตัวไหนไหนไม่อัพเดทก็ค่อยๆปรับไป ตัวไหนไม่ได้ใช้ก็ตัดออกไปเลย
